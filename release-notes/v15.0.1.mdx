## How to update

To run Mia-Platform v15.0.1, the following Helm chart versions must be installed on your cluster. For the complete installation sequence and per-product upgrade guides, see the [Installation Guidelines](/docs/requirements/installation-guidelines/overview).

| Product | Helm Chart | Version | Upgrade guide |
|---|---|---|---|
| **Auth — Keycloak** | `keycloak-operator` | `0.5.4` | [How to upgrade](/docs/requirements/installation-guidelines/shared-services/authn/keycloak/how-to-upgrade) |

| **AI Foundry** | `ai-foundry` | `0.4.79` | [How to upgrade](/docs/requirements/installation-guidelines/ai-foundry/how-to-upgrade) |
