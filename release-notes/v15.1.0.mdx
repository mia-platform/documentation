_Sep 17th, 2026_

## Suite Home

### Platform Administration

User and permission management is now available directly from the Suite UI.

* Organization admins can view organization users, their tenants, and assigned roles.
* Organization admins and Tenant admins can assign tenant-level roles to users.
* Catalog supports granular, item-level permissions for users and groups, while AI Foundry currently supports general static roles.
* Service Accounts can now be created directly from the Service Account section in the Suite.

### User Invitations

Users can now be invited to tenants directly from the Suite.

* Organization admins can send invitations and track their status (Pending or Accepted).
* Once accepted, users can be assigned roles, permissions, and groups.

## How to update

To move from Mia-Platform v15.0.2 to v15.1.0, update the Helm charts listed below. Products not listed here stay on the chart versions of the previous release notes. For the complete installation sequence, see the [Installation Guidelines](/docs/requirements/installation-guidelines/overview).

:::info
Starting from this release, Mia-Suite products can also be deployed all within the same namespace. You can either keep the existing multi-namespace deployment or opt for a single-namespace deployment. To learn how to configure this deployment modality, refer to the documentation in the [on-prem-charts repository](https://github.com/mia-platform/on-prem-charts/tree/v15.1.0).
:::
