## How to update

To run Mia-Platform v15.1.0, the following Helm chart versions must be installed on your cluster. For the complete installation sequence and per-product upgrade guides, see the [Installation Guidelines](/docs/requirements/installation-guidelines/overview).

### Helm chart versions

| Product | Helm Chart | Version | Upgrade guide |
|---|---|---|---|
| **Auth — Keycloak** | `keycloak-operator` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/shared-services/authn/keycloak/how-to-upgrade) |
| **Auth — Realm Management** | `keycloak-realm-management` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/shared-services/authn/keycloak-realm-management/how-to-upgrade) |
| **Homepage & RBAC** | `services` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/shared-services/services/how-to-upgrade) |
| **Catalog** | `catalog` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/catalog/how-to-upgrade) |
| **AI Foundry** | `ai-foundry` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/ai-foundry/how-to-upgrade) |
| **Console** | `console` | `vX.X.X` | [How to upgrade](/docs/requirements/installation-guidelines/console/self-hosted/how-to-upgrade) |
